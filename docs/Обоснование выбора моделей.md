# Обоснование выбора моделей для проверки подготовки к 3D-печати

Для проверки агента и пробной печати мы выбрали три модели с сайта [Printables](https://www.printables.com/). Мы расположили их по возрастанию сложности задачи для агента. В первом тесте достаточно запустить проверку, во втором нужно исправить ориентацию одной детали, а в третьем — ещё и разместить несколько деталей на одном печатном столе.

## 1. Ёлочная игрушка — запуск проверки

Игрушка представляет собой одну плоскую деталь с отверстием для подвеса, рядом небольших отверстий по краю и сквозным узором в форме следа лапы. В исходном файле игрушка уже лежит плоской стороной на столе. Поэтому она подходит для базового теста, в котором от агента требуется только запустить проверку модели в исходном положении.

## 2. Деталь светильника Wasted — исправление ориентации

Для второго теста мы взяли одну деталь светильника Wasted с прорезной надписью. В скачанном файле она уже лежала надписью вниз. Перед проверкой мы намеренно поставили её на бок, чтобы выяснить, сможет ли агент самостоятельно определить правильную ориентацию по геометрии букв.

В надписи есть отверстия и «островки» — отдельные участки материала внутри контуров букв. Когда деталь стоит на боку, первые слои некоторых островков приходится печатать в воздухе. Агент должен распознать эту проблему и положить деталь надписью вниз. Тогда печать островков начинается прямо на поверхности стола.

## 3. Крючок для вешалки — ориентация и размещение трёх деталей

Крючок выбран для самого сложного теста, поскольку состоит из трёх отдельных деталей. При подготовке детали с П-образной аркой важно учесть положение перемычки. Если поставить арку на две стойки, перемычку придётся печатать над проёмом. Агент должен выбрать правильную ориентацию.

Затем агенту нужно учесть место, которое займёт повёрнутая деталь, и разместить рядом две остальные. Критерий успешной подготовки — все три детали одновременно помещаются в рабочей области стола, не перекрывают друг друга и ориентированы для печати.
