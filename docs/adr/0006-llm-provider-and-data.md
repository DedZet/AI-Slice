# ADR-0006: Нейросеть подключаем через адаптер, файл модели ей не отправляем

- Статус: Принято
- Дата: 2026-11-12

## Контекст

В ТЗ есть два требования, которые влияют на выбор нейросети:

- кейс связан с технологическим суверенитетом, то есть нужен доступный отечественный контур;
- для пилота действует условие: нет передачи чувствительных данных без контроля. Заказчик будет давать обезличенные модели.

Мы пока не знаем, какая именно нейросеть покажет лучшее качество на наших задачах и какую разрешит использовать заказчик. Эти вопросы нужно будет обсудить с Силикроном.

## Решение

1. Все обращения к нейросети идут через один небольшой модуль-адаптер. Поставщик (облачный отечественный сервис, локальная модель или другой) меняется настройкой, без переписывания остального кода.
2. Наружу, к нейросети, уходит только текст: числа из анализа (ADR-0005), выбранный принтер и материал, комментарий пользователя. Сам файл модели и его геометрия не отправляются.
3. Для разработки используем любую доступную модель. Для пилота выберем отечественную или локальную после проверки на 3-5 тестовых моделях и согласования с заказчиком.

## Рассмотренные варианты

- Привязаться к одному облачному сервису. Проще, но смена поставщика потом потребует переписывать код, и мы можем не пройти по требованию заказчика.
- Использовать только локальную модель. Данные остаются внутри, но нужно подходящее оборудование, и качество на старте может быть ниже. Оставляем как один из вариантов, который подключается через тот же адаптер.
- Отправлять в нейросеть сам файл модели. Это лишний риск для данных и не нужно, потому что геометрию считает код (ADR-0005).
- Адаптер и отправка только описания (выбрано).

## Последствия

Плюсы:

- Данные заказчика остаются под контролем, это прямо отвечает критерию пилота.
- Поставщика можно поменять, если качество или условия не подойдут.

Минусы:

- Разные нейросети по-разному вызывают инструменты MCP. Придётся проверить работу на каждой из них.
- Открытый вопрос: какая именно модель пойдёт в пилот. Когда решим, запишем это отдельным ADR.
