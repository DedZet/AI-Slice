# ADR-0007: Результат хранится как один набор параметров, который правят и ИИ, и человек

- Статус: Принято
- Дата: 2026-11-12

## Контекст

По ответу преподавателя, если пользователя что-то не устраивает, он может повторно запросить исправление у нейросети или поправить настройки вручную. Оба способа меняют один и тот же результат. Если нейросеть и человек будут менять разные данные в разных местах, начнётся путаница: ручные правки потеряются после повторного запроса, а в G-коде окажется то, чего никто не видел.

В ТЗ также нужны воспроизводимый сценарий нарезки и объяснимые рекомендации.

## Решение

Результат работы хранится как один набор параметров в файле проекта (формат JSON). В нём: принтер, материал, положение модели, поддержки, заполнение, температуры, скорость, а рядом с каждым важным значением - короткое пояснение, почему оно такое.

Правила:

- Нейросеть записывает свои значения в этот набор. Человек правит те же поля в интерфейсе (ADR-0003).
- G-код всегда получаем заново из этого набора, вручную его не правим.
- У каждого изменения запоминаем, кто его сделал (ИИ или человек) и когда. Можно вернуться к предыдущей версии.
- Повторный запрос к нейросети не должен затирать поля, которые поменял человек, если пользователь прямо не попросил об этом.
- Проект для печати (.3mf) формируем средствами OrcaSlicer. Если из командной строки его сохранить не получится (проверяем в первую неделю, см. ADR-0002), отдаём модель в выбранном положении и файлы настроек.

## Рассмотренные варианты

- Править G-код напрямую. Он плохо читается, и любая правка легко ломает печать.
- Хранить всё только внутри проекта OrcaSlicer. Простые параметры и пояснения там не видны, истории "ИИ или человек" нет.
- Хранить только переписку с нейросетью. По переписке трудно восстановить итоговые настройки.
- Один набор параметров (выбрано).

## Последствия

Плюсы:

- Результат воспроизводится: по одному файлу можно получить тот же G-код.
- Видно, что поменяла нейросеть, а что человек. Это важно для ручного контроля (ADR-0008).

Минусы:

- Нужно заранее составить список параметров для MVP и связать каждый с настройкой OrcaSlicer.
- Если в OrcaSlicer появятся новые настройки, в нашем наборе их не будет, пока мы их не добавим.
