# ADR-0005: Геометрию считает код, решения и объяснения даёт нейросеть

- Статус: Принято
- Дата: 2026-11-12

## Контекст

По ответу преподавателя система должна работать даже без комментария пользователя и сама проводить базовый анализ модели. Пример из ответа: П-образную деталь нужно поставить вверх ногами, чтобы арка не провисала при печати.

Файл модели - это тысячи треугольников. Нейросеть плохо измеряет такие данные: она может ошибиться в размерах или не заметить нависание. При этом именно она хорошо умеет сопоставить данные, выбрать вариант, учесть комментарий пользователя и объяснить выбор человеческим языком (ТЗ требует объяснимый отчёт).

## Решение

Разделяем работу:

1. Обычный код анализирует модель. Для нескольких вариантов положения на столе (в первой версии - по одному на каждую из шести сторон детали) он считает: габариты, площадь касания со столом, площадь нависаний круче допустимого угла, примерный объём поддержек, места с тонкими стенками.
2. Результат - короткая таблица чисел. Её получает нейросеть.
3. Нейросеть выбирает положение и параметры печати, учитывает комментарий, если он есть, и пишет пояснение со ссылкой на эти числа.

Для П-образной детали это работает так: в положении "на ножках" арка сильно висит, и код покажет большую площадь нависания. В положении "вверх ногами" нависания почти нет. Нейросеть выбирает второй вариант и объясняет почему.

## Рассмотренные варианты

- Отдавать нейросети картинки модели и ждать, что она всё поймёт по изображению. Менее точно, дороже и результат трудно проверить. Можно рассмотреть позже как дополнение.
- Обойтись одними правилами без нейросети. Результат повторяемый, но нет учёта комментария пользователя, нет объяснений и нет смысла называть решение агентным.
- Код считает, нейросеть решает (выбрано).

## Последствия

Плюсы:

- Числа можно проверить и показать пользователю, поэтому решение не выглядит "чёрным ящиком".
- Результат лучше повторяется: одна и та же модель даёт одни и те же числа.
- Есть что показать как метрику: можно сравнить выбор системы с выбором инженера.

Минусы:

- Анализ придётся написать самим.
- В первой версии положения перебираем только "гранями вниз". Произвольные углы наклона не рассматриваем.
