# Каталог AI-SLICE

Профили принтера, материала и базовые процессы взяты из [исходников OrcaSlicer v2.5.2](https://github.com/OrcaSlicer/OrcaSlicer/tree/v2.5.2/resources/profiles). Лицензия исходного проекта сохранена в [ORCASLICER-LICENSE.txt](ORCASLICER-LICENSE.txt).

Каталог содержит 77 сочетаний принтера и материала для 17 моделей Bambu Lab, Creality, Prusa, Anycubic и Elegoo с соплом 0,4 мм. Материалы PLA, PETG, ABS, ASA, TPU, PC и PA доступны там, где есть подходящий исходный пресет. ABS, ASA, PC и PA включены для закрытых принтеров из каталога. Для каждого сочетания доступны варианты процесса с упором на баланс, прочность, детализацию или скорость, с древовидными поддержками и с отключёнными поддержками.

Скрипт раскрывает наследование и вставки OrcaSlicer, использует совместимые пресеты филамента и подставляет фиксированные значения высоты слоя, числа периметров, заполнения и поддержек. Это стартовые варианты на базе штатных пресетов. Тип пластины указан в манифесте и в плане печати. Калибровка и проверка на конкретном принтере и филаменте выполняются командой проекта.

Для повторной генерации используйте исходный checkout официального тега, который содержит JSON профилей.

```powershell
python src/backend/import_orca_profiles.py <orca-source>/resources/profiles src/profiles
```

Для добавления своей конфигурации создайте отдельную папку с `profile.json` и JSON пресетами либо добавьте модель в таблицу генератора.
