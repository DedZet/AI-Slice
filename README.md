В этой папке лежат записи о ключевых решениях по проекту (ADR). Одно решение - один файл. Из них можно понять, почему мы сделали именно так, а не иначе.

## Как добавить новое решение

1. Скопировать любой файл как образец и взять следующий номер.
2. Назвать файл так: `0123-короткое-название.md` (латиницей, через дефисы).
3. Заполнить разделы: статус, дата, контекст, решение, рассмотренные варианты, последствия.
4. Принятые решения не переписываем. Если решение поменялось, создаём новый файл, а в старом ставим статус "Заменено решением 00XX". Небольшие уточнения того же дня или опечатки можно вносить в файл, указав это в строке "Уточнено".
5. Добавить строку в таблицу выше.

Возможные статусы: Предложено, Принято, Отклонено, Заменено.


Помоги спроектировать и реализовать систему автоматической подготовки и нарезки 3D-моделей через веб-чат, LLM и наш MCP-сервер.

Стек:
- Фронтенд: React (веб-интерфейс чата, загрузка модели, отображение статуса/метрик и скачивание результата).
- Бэкенд: FastAPI (REST/WebSocket API, управление задачами `job_id`, файловое хранилище, оркестрация диалога с LLM API и вызов MCP).
- MCP-сервер и вычислительные модули (на сервере рядом с OrcaSlicer):
  1. Модуль геометрического анализа 3D-сеток (Trimesh, libigl): обнаружение нависаний, мостов и тонких стенок, расчёт центра тяжести и площади контакта со столом, оценка пригодности модели к печати. Входные форматы: STL (MVP), далее STEP и 3MF.
  2. Алгоритм подбора ориентации детали: расчёт/оценка ориентации с учётом направления нагрузки, площади контакта со столом и необходимости поддержек.
  3. Алгоритм подбора заполнения и древовидных поддержек: выбор параметров под материал (PLA, PETG, ABS) строго в пределах проверенных профилей материалов и принтеров.
  4. Исполнитель OrcaSlicer CLI: запуск локально установленного OrcaSlicer в headless-режиме с подготовленной моделью/ориентацией, выбранными профилями и параметрами, с выгрузкой результата (`.gcode.3mf` / `.gcode`, время печати, расход материала).

Архитектура и поток данных:
1. Пользователь в React-интерфейсе загружает 3D-модель (на MVP — STL, далее STEP и 3MF) и пишет пожелания по печати (прочность, направление нагрузки, качество, скорость, материал PLA/PETG/ABS, заполнение, поддержки и т.д.).
2. FastAPI сохраняет файл в изолированной директории задачи (`job_id`) на сервере и отправляет запрос в LLM API с описанием MCP-инструментов и доступных проверенных профилей.
3. LLM через MCP вызывает нужные инструменты: геометрический анализ -> подбор ориентации -> подбор заполнения и древовидных поддержек под материал в рамках проверенных профилей -> запуск OrcaSlicer CLI.
4. Результаты шагов и итоговый файл/метрики возвращаются в FastAPI и отдаются пользователю в React-чат.
