# Журнал решений проекта AI-SLICE

Проект: AI-SLICE. Умная нарезка моделей для 3D-печати.

В этой папке лежат записи о ключевых решениях по проекту (ADR). Одно решение - один файл. Из них можно понять, почему мы сделали именно так, а не иначе.

## Как добавить новое решение

1. Скопировать любой файл как образец и взять следующий номер.
2. Назвать файл так: `0123-короткое-название.md` (латиницей, через дефисы).
3. Заполнить разделы: статус, дата, контекст, решение, рассмотренные варианты, последствия.
4. Принятые решения не переписываем. Если решение поменялось, создаём новый файл, а в старом ставим статус "Заменено решением 00XX". Небольшие уточнения того же дня или опечатки можно вносить в файл, указав это в строке "Уточнено".
5. Добавить строку в таблицу выше.

Возможные статусы: Предложено, Принято, Отклонено, Заменено.
